# Картинки к статье

Две схемы готовы и от стенда не зависят:

- `docs/img/topology.svg` — топология, адресация, врезка про двойные имена
  интерфейсов (`eth4` в топологии против `et-0/0/0` в конфиге)
- `docs/img/packet-path.svg` — три точки захвата и место, где умирает пакет

Остальное — **настоящие снимки экрана с живого стенда**, снимать самому.

## Важно про порядок

Стенд поднят скриптом `scripts/05-deploy-broken.sh`, то есть **намеренно без**
`forwarding-options tunnel-termination`. В этом состоянии контрол-плейн
идеален, а трафика нет. Сначала снимаем сломанное состояние, и только потом
применяем починку — обратно сломать можно, но это ещё двадцать минут
загрузки.

Перед съёмкой: терминал на тёмной теме, шрифт крупный, окно широкое — иначе
таблицы Junos переносятся и на Хабре выглядят отвратительно.

## Кадр 1. Контрол-плейн, который врёт

Вход на узел, чтобы в приглашении было честное `admin@leaf1`:

```bash
wsl -d clab -u root
```

```bash
ssh admin@172.20.20.3
```

Пароль `admin@123` (leaf1 = 172.20.20.3, leaf2 = 172.20.20.4). Дальше три команды подряд, снимать одним кадром:

```
show bgp summary
show mac-vrf forwarding mac-table
show evpn database
```

Что должно быть видно: обе сессии в `Establ`, в MAC-таблице чужой MAC
с флагом `DR` через `vtep-54.32770`, в базе EVPN — MAC хоста из-за соседнего
листа. Всё зелёное.

## Кадр 2. И ни одного пакета

```bash
docker exec -it clab-evpn2-h1 sh
```

```
ping -c 5 10.10.10.2
ip neigh show
```

Должно быть `100% packet loss` и `INCOMPLETE`. Это кульминация, кадр
главный в статье. Хорошо, если в одном кадре поместится вместе с первым.

## Кадр 3. Три tcpdump

Из рут-шелла WSL, каждый в своём окне или по очереди:

```bash
nsenter -t $(docker inspect -f '{{.State.Pid}}' clab-evpn2-leaf1) -n tcpdump -nni eth4 'udp port 4789 or arp'
```

```bash
nsenter -t $(docker inspect -f '{{.State.Pid}}' clab-evpn2-leaf2) -n tcpdump -nni eth4 'udp port 4789'
```

```bash
nsenter -t $(docker inspect -f '{{.State.Pid}}' clab-evpn2-h2) -n tcpdump -nni eth1 'arp or icmp'
```

Третий покажет `0 packets captured` — ради этого кадра всё и делается.
Пока захваты висят, в другом окне гонять пинг с h1, иначе ловить нечего.

## Кадр 4. Починка

Только после того, как первые три отсняты. На обоих узлах:

```
configure
set forwarding-options tunnel-termination
commit
```

и сразу пинг с хоста — `0% packet loss`, RTT около 1 мс. Красиво смотрится
одним кадром: коммит и сразу живой пинг.

## Кадр 5. Замеры

```bash
bash /root/04-measure.sh
```

Выдаёт базовую линию и прогон с отказом линка. Можно снимком, можно просто
кодом в тексте — числа в JSON читаются и так.

## Чего не снимать

- Страницы Juniper, загрузку образа, `docker images`, `wsl --version` —
  это текст, а не картинка, на Хабре смотрится как наполнитель.
- Ничего с рабочего контура. На стенде такого нет, но перед публикацией
  пробежаться глазами по приглашениям и именам: должны быть `leaf1`,
  `leaf2`, `clab-evpn2-*` и адреса из `10.x` и `172.20.20.x`.
